## How this inventory was produced

- The component list is generated from the project's `Cargo.lock`
  (299 registry packages, exact versions) — the same lockfile that
  pins every dependency of the shipped binaries.
- Each component's license is the **declared SPDX expression** published for
  that exact crate version on crates.io (fetched 2026-09-05).
- **License file contents were collected from the actual cargo registry
  sources** (2026-09-06): for every package the `.crate` archive was
  downloaded from `static.crates.io` and every top-level license-like file
  (`LICENSE*`, `LICENCE*`, `COPYING*`, `UNLICENSE*`, `LICENSES/*`) was
  captured verbatim. 292/299 packages ship at least one
  license file in their registry source; the 7 that do not are flagged in
  [Unresolved and flagged notices](#unresolved-and-flagged-notices) below.
- Where a crate offers a choice (`OR`), the **selected** license is
  recorded in the table and the verbatim text of the selected license (as
  shipped in the crate's own file) is included. Where several licenses
  apply together (`AND`), all of them are included.
- Texts that are **byte-identical** across packages are listed once and
  shared (deduplicated by SHA-256 of the file bytes). No other
  deduplication is performed: crate-specific copyright notices are
  preserved verbatim and never replaced by a generic template.
- The canonical SPDX license texts published under
  [`third-party/licenses/`](third-party/licenses/) in the public release
  repository remain as a **supplemental** reference (and are used where a
  package's registry source lacks the applicable file, as flagged below).
- This inventory covers the full dependency graph of the lockfile (all
  target platforms). The set actually linked into a given binary is a
  platform-specific subset of that list.
- This is a best-efforts, evidence-based inventory: the per-crate texts are
  the files actually shipped in the registry source, and every gap is
  flagged in [Unresolved and flagged notices](#unresolved-and-flagged-notices)
  instead of being papered over. If you identify a discrepancy, please
  report it (see [`docs/SECURITY.md`](docs/SECURITY.md) for the reporting
  channel). This file does not constitute legal advice and does not claim
  completeness beyond the evidence described here.
